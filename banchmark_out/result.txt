nQ = queries with a correct answer (the only ones R@1/mAP average over).
pairF1*  = ORACLE: max F1 swept over thresholds on THIS (test) matrix. It is an
           upper bound no deployment can pick, and is not comparable with assF1.
pairF1@v = the same curve read at the threshold calibrated on VALIDATION -- the
           number a deployed system gets. Quote this one; quote pairF1* as a ceiling.
assF1  = one-to-one assignment F1 at the validation-calibrated threshold.
scored = fraction of valid pairs the method returned a finite score for.
         Below 1.00 is a PENALTY, not an easier subset: an unscored pair takes the
         fail distance, ranks last, and its query is still counted. See the
         coverage breakdown in results.json for what the missing fraction is made of.
total_s = prepare + score. Embedding methods do all their work in prepare.

Provenance: the ten crop-scope rows and the four crop(+ctx) controls plus
coverage-only were run together (benchmark.py --ablations --controls); SuperGlue
and LoFTR were run separately afterward, once, to add pairF1@v -- their earlier
run had no validation matrix scored, so no calibrated threshold existed. Cost
(total_s) is wall-clock on one workstation and is not controlled for load
between separate runs; the compute-span claim in the paper is therefore stated
qualitatively ("more than three orders of magnitude"), not as a precise
multiplier, and cites the two measured endpoints (CrackShape, LoFTR) directly.
registration+chamfer is the full cascade with ECC enabled (Sec. VI-F); the
disabled-ECC ablation is a separate reported condition, not a row here.
