\section{Benchmark Protocol}
\label{sec:protocol}

The benchmark evaluates open-set retrieval: a photographed crack may or may
not have a corresponding gallery instance. The protocol retains unknown
cracks, calibrates thresholds on validation walls, and charges methods for
unscorable pairs.

A \emph{wall} is one physical wall at the capture site; all gallery candidates
for a query come from that wall. An \emph{identity} is a dataset label for a
crack tracked across photographs, not an independently audited physical-
identity judgment. A \emph{query} is one annotated crack instance in a
photograph. Its \emph{gallery} contains instances from eligible photographs
of the same wall, excluding the query photograph and capture session. A query
is \emph{known} if at least one valid gallery instance has the same identity;
otherwise it is \emph{unknown}. Test contains 306 answerable (known) and 199 unknown
queries on the current labels ($30\,390$ valid pairs, $6\,160$ positive,
prevalence $0.203$, floor $0.337$; \texttt{banchmark\_out/chance\_nq305.json}).
Table~\ref{tab:units} retains the prior-pool recount for provenance; its test
positives/valid counts ($5\,722/31\,822$) are superseded for the crop rerun.
A \emph{query--gallery pair} is one query compared with one eligible
gallery instance; an \emph{image pair} is two photographs of the same wall and
is the unit charged for registration. Table~\ref{tab:units} summarizes the
pair and image-pair counts. On test, registration is attempted for all $301$
same-wall image pairs; $255$ contain at least one scored crack instance and
produce validity-mask cells, while $46$ yield no valid query--gallery pair
after the $200$\,px size filter (see Sec.~\ref{sec:coverage}).

\subsection{Metrics}
Ranking uses Rank-1, Rank-5, and mAP over known queries. Pairwise $F_1$
classifies each valid query--gallery pair. Assignment $F_1$ ($F_1^{a}$ in
Table~\ref{tab:hybrid}) evaluates the
one-to-one matches made independently for each image pair. We distinguish
$F_1^{*}$ (oracle threshold on test, a ceiling no deployment can pick),
$F_1^{@v}$ (threshold calibrated on held-out validation walls, the deployable
number), and $F_1^{a}$ (assignment at the validation threshold). At threshold $t$,
$\mathrm{FAR}(t)$ is the fraction of unknown queries whose highest finite
gallery score is at least $t$; $\mathrm{DIR}(t)$ is the fraction of known
queries whose highest-scoring gallery instance is both correct and at least
$t$. The reported $\mathrm{DIR}@\mathrm{FAR}{=}0.1$ is the largest DIR among
thresholds whose FAR is at most $0.1$ (a conservative open-set operating
point; unknown queries with no finite score count as correct rejections,
known queries with no finite score count as misses).

For assignment $F_1$, the Hungarian algorithm maximizes total score within
each query-image/gallery-image block; assignments below the validation-chosen
threshold are rejected. Correct assignments are true positives, incorrect
accepted assignments are false positives, and unmatched known queries are
false negatives. Thus $F_1=2TP/(2TP+FP+FN)$; unmatched unknown queries are
correct rejections. Unscorable pairs count as predicted negative for pairwise
and assignment $F_1$ and rank last for retrieval. A known query with no finite
score is a miss, while an unknown query with no finite score is not a false
alarm.

Every metric is reported against its chance level, because two are far from
zero (current test pool, \texttt{chance\_nq305.json}: $200$ random matrices): pairwise $F_1$ has a best-constant-predictor floor
$2p/(1+p) = 0.337$ at prevalence $0.203$, Rank-5 chance $0.778{\pm}0.019$, mAP $0.382$; Rank-1
$0.336{\pm}0.025$ and
$\mathrm{DIR}@\mathrm{FAR}$ $0.038{\pm}0.014$, assignment-$F_1$ $0.345$. Prior-pool values were $0.305/0.767/0.336/0.038$. We call $2p/(1+p)$
a floor, not coin-flip chance: it is the score of predicting every pair
positive, and it changes when
the evaluated pair pool changes. Confidence resampling uses walls rather than
queries because queries from one wall share capture conditions. With 11 test
walls, no numeric interval is attached; wall-level intervals await a larger
dataset and release of the per-pair score matrices (Sec.~\ref{sec:validity}).
