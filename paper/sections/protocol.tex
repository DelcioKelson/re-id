\section{Benchmark Protocol}



\label{sec:protocol}



The benchmark tests visual association: for a new crack photograph, decide whether it shows a recorded crack. Annotated crack identities stand in for ticket records. Scores therefore measure association accuracy, not ticket-level duplicate reduction.



\subsection{Task formulation and candidate records}



A single identity is established by using photographs of the same physical crack. By 'instance' is meant one mask component in a single photograph; the 'query' is the instance that is being linked; a 'valid pair' is a query and a gallery cell that is accepted by the mask (specifically, the same wall but taken at a different time); a 'photograph block' consists of all the cells from one photograph pair and is the unit used for Hungarian assignment. Search across walls is not permitted. A query is considered 'known' if its gallery includes its identity; otherwise it is 'unknown' (in this case it is a singleton within one photograph only; singletons can differ in size or border distance, so FAR might indicate the rejection of fragments; see Sec.~\ref{sec:validity}). In closed-set retrieval only ranking is performed; in open-set identification links are made to the best ticket or the query is rejected as a new ticket. Pairs are the unit for making decisions; queries are used in retrieval and in open-set identification; photograph pairs are used for registration and assignment. The Hungarian one-to-one matching is applied separately to each photograph pair; the assignment $F_1$ is calculated but is not presented as a headline result.



Counts for the frozen snapshot (6 validation walls 01--06; 11 test walls 07--17; walls 18--19 excluded): validation has 6 walls / 66 photographs / 66 identities (18 matchable, 439 known queries, 74 open-set); test has 11 walls / 74 photographs / 146 identities (19 matchable, 280 known queries, 258 open-set); positive query--gallery pairs: 26,012 validation / 5,722 test; valid query--gallery pairs: 89,118 / 31,822. Of 301 same-wall test photograph pairs, 255 have valid cells and 97 register successfully. Of 31,822 valid test query--gallery pairs, 15,328 fall inside registered pairs (48\%).









\subsection{Test conditions, decisions, and metrics}



The main test involves actual walk-arounds assuming that the morphology remains unaltered; the variables included are viewpoint, distance, scale, lighting and visibility, as well as same-wall distractors and unknowns, with no separation being made according to gap, scale or surface. The validation and test walls are not connected. The appearance methods are run using the version released on the shared masks without any \textsc{CrackID} tuning; the geometry settings (tolerance $[2,16]$~px, early-rejection distance, sharpness gate, Random Sample Consensus (RANSAC)~\cite{fischler1987ransac} inliers, scale $[1/16,16]$) are not fixed during validation and should be set before any final comparison. The masks are derived from a UNet++~\cite{zhou2018unetplusplus,ronneberger2015unet} combined with a ResNet-34~\cite{he2016resnet} that was trained on cracks available from the public dataset only (without use of a \textsc{CrackID} wall), and this is taken as given with the error left unmeasured. For ORB/SIFT the RANSAC inliers are used, for SuperGlue/LoFTR the indoor match counts are employed, and for the embeddings the cosine value on L2 crops is taken. The inpainting control makes use of Telea after a 5~px dilation (see Sec.~\ref{sec:ceiling}). The chance value is $2p/(1{+}p)$ together with 200 random matrices: the $F_1$ score is 0.305 at a prevalence of 0.180, 0.544 on the registered subset (0.373), and 0.452 on validation (0.292); for random Rank-1 it is 0.336, the mean average precision (mAP) is 0.385, the detection-and-identification rate (DIR) is 0.038 at a false alarm rate (FAR) of 0.1. The seeds are fixed; the spread is not reported.



Decisions: pairs above the validation threshold are accepted; open set accepts only the top gallery entry above threshold, else rejects as new ticket. Hungarian applies per block, dropping below-threshold pairs. Unregistered pairs stay in: predicted negative for $F_1$, ranked last; unregistered unknowns count as correct rejections while unregistered knowns count as misses, so FAR uses all 258 unknowns (102 with no registered candidate). Registration failure is absence of evidence, not evidence of a new crack. Metrics are defined in Table~\ref{tab:main} caption; within-visit only.
